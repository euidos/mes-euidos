# praxis/ — authored process-model shards

Committed source for the work-world model of this app (praxis-v0 ontology):
objects (lifecycles, role bindings), activities, gates. Static extraction
derives the codified layer from the code; shards here carry what code cannot
say (intent, target-state prescriptions). `.praxis/board/` holds the
process-domain whiteboard; this directory holds the model. Client Praxis
views compose this app's model with the client app's (mes-<client>).
