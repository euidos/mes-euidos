### 진입

```
설비에 붙은 QR 스티커  →  https://.../app/work-execution?ws=IJ03
      │
      ├ 로그인 세션 없음 → 로그인 화면 → 로그인 후 원래 화면
      └ 세션 있음        → 바로 IJ03 실행 화면
```

**QR은 설비를 지정할 뿐 인증을 건너뛰지 않음.** 폰 브라우저가 세션을 유지하므로 재로그인은
사실상 최초 1회. 계정 없는 사람이 스캔하면 로그인 화면에서 막힘.

매 요청 서버 검증: 세션 → 역할 → 이 설비·이 작업지시 범위 → WO 상태(진행 중인가).
비로그인(Guest) 입력은 허용하지 않음 — 실적은 재고를 움직이는 데이터.

### 화면에 표시되는 것

| 구분 | 내용 | 출처 |
|---|---|---|
| 컨텍스트 | 호기·작업자·WO·품목·LOT | Workstation / Job Card / Batch |
| 지시 | 목표·잔량·납기·공정 | Work Order |
| 금형 | 금형번호, 누적 타수 / 수명 | MES Mold |
| 진행 | 양품·불량 누계, 진행률 | Job Card |
| 속도 | 표준 사이클타임 vs 실제 | BOM Operation vs 실적 |
| 문서 | 도면·성형조건표 유효본 | MES Document |
| 경고 | 금형 수명, 레진 잔량, 연속 불량 | 각 마스터 |

### 입력과 주기

| 동작 | 주기 | 남는 것 |
|---|---|---|
| 작업 시작 | 1회 | Job Card 시작 + LOT 발번 |
| 양품 수량 | **이벤트·마감 시점** | Job Card 실적 |
| 불량 수량 + 코드 | 이벤트·마감 시점 | 품질 분석 근거 |
| **비가동 시작·종료** | **발생 즉시** | OEE 가동률 근거 |
| **금형 교체** | 발생 즉시 | 타수 확정 · 금형 위치 · **새 LOT** |
| **원료 로트 투입** | 발생 즉시 | 자재 소비 · **새 LOT** |
| **조건 변경 신고** | 발생 즉시 | **새 LOT** |
| 작업 종료 | 1회 | 완제품 입고 전표 |

**절단면 = LOT 경계.** 원료를 교체할 때 "지금까지 420개"를 입력하고 새 LOT을 여는 방식이라
수량 배분 문제가 원천적으로 없음. 하루 입력 2~5회.

## Why

**박스·팔레트 단위 입력을 기본에서 뺀 이유**: 박스 단위의 진짜 이득은 박스별 추적(박스 단위 회수,
납품 라벨의 박스 번호)인데 고객이 요구할 때만 필요함. 요구가 없으면 입력 횟수만 10배(20~50회).
LOT 정합성은 이벤트 시점 입력으로 동일하게 확보됨.

수량 세기 부담도 낮음 — 사출기에 shot 카운터가 있어 현장은 세는 게 아니라 읽음.
LOT 라벨은 박스 등록과 무관 — 같은 LOT이면 라벨이 동일하므로 미리 출력해 붙임(현장 관행).

**포기하는 것**: 박스별 추적, 진행률 해상도(하루 2~5회 갱신), 불량 사유 정밀도(마감 시 회상).
앞의 둘은 중소 규모에서 감당 가능, 셋째는 박스 단위로 올리면 해소 — 전부 문진 항목.

**비가동만 즉시인 이유**: OEE = 가동률 × 성능 × 양품률. 가동률을 계산하려면 정지 시각과 사유가
필요한데, 마감 시 "오늘 1시간 30분 멈춤"으로 뭉개면 개선 지점을 못 찾음.

## History

- 초안: **박스·팔레트 단위** 입력 기본. `superseded`
  - 폐기 사유: 사용자 제안(이벤트·마감 시점 입력)이 LOT 배분 문제를 동일하게 해결하면서
    입력 횟수가 1/10. 박스 단위의 이득은 박스별 추적뿐이고 그것은 고객 요구 사항.
- 초안: 현장 단말 고정 + 공용 계정. `superseded`
  - 폐기 사유: 타겟이 중소 제조업이라 단말이 없는 것이 기본값. QR + 작업자 개인폰으로 전환.

## Memory

**오프라인 미지원** — 와이파이가 끊기면 입력 불가. 브라우저 큐 방식은 중복 전송·순서 꼬임 처리가
붙어 비용이 큼. 특히 LOT 분기 이벤트가 오프라인 중 발생하면 순서가 꼬여 추적성이 깨지므로,
나중에 오프라인을 붙이더라도 **이벤트 계열은 온라인 필수**로 남겨야 함.

공장 와이파이는 업체 부담 (문진). 없으면 폰 데이터로 외부 접속 → 서버 인터넷 노출 →
방화벽·VPN 문제. 업체가 판단.

입력 동작이 만드는 전표:
```
작업 종료 → Stock Entry (제조)
              ├ 소비: 레진 (배치 지정, WIP 창고에서)
              ├ 산출: 완제품 (LOT)
              └ 산출: 재생재 (scrap_warehouse)
불량       → 불량 창고 (판정 대기)
```

화면은 Desk 커스텀 페이지로 통일 (`[[decision-ui-architecture]]`). 작업자도 System User.
Desk 껍데기가 폰에서 자리를 먹으므로 `single_column` + 상단바 접기 등 전체화면 처리가 필요 —
실제로 붙여보고 조정할 영역이라 미확정.
