| 기준 | **A. 실적 기반 + 보정** | B. 설비 카운터 신호 | C. 수동 입력 |
|---|---|---|---|
| 계산 | `(양품 + 불량) ÷ total_cavity` + 보정 입력 | 사출기 shot 카운터 | 사람이 기입 |
| 개발 | 실적 등록 시 가산 1회 | 설비 인터페이스 필요 | 0 |
| 정확도 | 보정으로 메움 | 정확 | 부정확 |
| 업체 조건 | 없음 | 신호 수집 가능 설비만 | 없음 |

**채택: A + 보정.** 불량 수량까지 포함해 가산하고, 시험타·공타는 실적 화면의 `추가 타수` 입력란으로 보정.
B는 문진 18번(설비 신호 수집)이 켜진 업체에서 A를 대체.

**수명 도달 시 = 경고만.** 생산 차단 안 함.

| 시스템이 하는 것 | 시스템이 안 하는 것 |
|---|---|
| `total_shots / life_shots` 도달률 표시 | 마모 여부 판정 |
| 보전 주기 도래 알림 | 수명 자동 산출 |
| 수명 도달 경고 | 생산 차단 |

보전 알림 조건: `total_shots - last_maintenance_shots >= maintenance_interval_shots`

## Why

**금형은 양품이 안 나와도 닳음** — 시험타(조건 잡는 shot), 미성형·버 불량, 공타 전부 타수를 올림.
양품 수량만으로 가산하면 실제보다 **적게** 집계되어 수명 도달을 늦게 인지함. 틀리는 방향이 위험한 쪽.

차단을 안 하는 이유: `life_shots`는 사양상 추정치라 실제로는 초과해서 쓰는 일이 흔함.
막으면 현장이 우회 경로를 만들고 그 시점부터 데이터가 더 나빠짐. 차단이 필요한 업체는 문진 11번.

## Memory

**수명 타수는 측정값이 아니라 사양값** — 금형 등록 시 사람이 입력. 시스템이 산출할 수 없음.

근거가 되는 것:
- 금형 재질·열처리 (사출 기준 대략): S45C 연강 ~10만 타 / P20·NAK80 프리하든 30~50만 /
  SKD61·STAVAX 열처리 100만+
- 수지 종류: 유리섬유 강화(GF)는 연마재처럼 작용해 마모 급가속, 같은 금형도 수명 절반 이하
- 금형업체 보증 타수 (제작 계약에 명시되는 경우가 많고, 고객 지급 금형이면 고객이 제시)

**실제 수명 도달은 타수가 아니라 증상으로 옴:** 버(flash) 증가(형합면 마모), 치수 공차 이탈,
게이트 주변 마모로 인한 충전 불량, 같은 제품인데 사출 압력·온도를 계속 올려야 성형되는 현상.
→ 타수는 예고 지표이고 판정은 품질 데이터가 함. 마모 판정 기능을 따로 만들지 않는 이유 —
품질 단계에서 불량 코드에 `버`·`치수이탈`을 두면 금형별 추세로 자연히 나옴.

**수명 도달 ≠ 폐기.** 대개 대수리(코어 교체·형합면 연마)로 되살리며 실질 수명이 리셋됨.
현재는 `total_shots` 수동 보정으로 처리. 별도 리셋 기능은 요구 발생 시.
