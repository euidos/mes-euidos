**1차(PC) 화면의 성격 = 실행 현황.** 현장 단말이 아님 — 반장·관리자가 **보고**, 필요 시 입력.
현장 작업자용 입력 전용 페이지는 모바일 단계(QR)에서 별도.

| | 1차 · PC | 나중 · 모바일 QR |
|---|---|---|
| 누가 | 반장·관리자 | 현장 작업자 |
| 목적 | 보기 + 입력 | **입력만** |
| 화면 | 진행 현황 전체 | 버튼 몇 개, 최소 |

### 구성

```
┌ 실행 현황                                          [새로고침] ┐
│ ┌──────────┐ ┌──────────┐ ┌──────────┐ ┌──────────┐        │
│ │ IJ03     │ │ IJ05     │ │ 조립대1  │ │ 검사기1  │        │
│ │ FG-A100  │ │ FG-B200  │ │  대기    │ │ 비가동   │        │
│ │ 62%      │ │ 31%      │ │          │ │ 25분     │        │
│ │9,920/16,000│1,550/5,000│          │ │          │        │
│ └──────────┘ └──────────┘ └──────────┘ └──────────┘        │
├─────────────────────────────────────────────────────────────┤
│ 선택한 작업 패널                                             │
│   IJ03 / WO-00042 / LOT 260801-IJ03-001                     │
│   [실적 입력] [불량 입력] [비가동] [원료 교체] [작업 종료]    │
└─────────────────────────────────────────────────────────────┘
```

- 상단: 설비별 현재 상태를 한눈에 (여러 설비 동시)
- 하단: 선택한 작업의 입력 패널

### 입력

| 동작 | 주기 | 남는 것 |
|---|---|---|
| 실적(양품) | 이벤트·마감 시점 | Job Card 실적 |
| 불량 | 이벤트·마감 시점 | 수량 + **간단 사유 코드** |
| 비가동 시작·종료 | 발생 즉시 | OEE 가동률 근거 |
| 원료 로트 교체 | 발생 즉시 | 자재 소비 + **새 LOT** |
| 조건 변경 | 발생 즉시 | **새 LOT** |
| 금형 교체 | 발생 즉시 | `use_mold` 켜짐일 때만 |
| 작업 종료 | 1회 | 완제품 입고 전표 |

**작업자 필드** — `Employee` 선택. **기본값 = 로그인 사용자에 연결된 Employee**(없으면 빈 값).
모바일 단계에서는 이 기본값이 그대로 정답이 됨.

**불량 사유** — 3~5개짜리 임시 목록으로 시작(외관·치수·기타 등). 정식 코드 체계는 5번 품질 단계.

## Why

**임시 사유 코드라도 받는 이유**: 지금까지의 원칙 — 안 받은 데이터는 소급할 수 없음.
코드 체계가 정교해져도 임시 코드는 매핑 가능하지만, 수량만 받으면 과거 데이터에 사유가 영구히 없음.

**작업자 기본값을 로그인 사용자로 두는 이유**: 모바일에서는 로그인 사용자 = 작업자가 되므로
그때 규칙이 그대로 이어짐. PC에서 반장이 대신 입력할 때만 선택으로 바꿈.

**1차에서 작업자 개인 계정이 불필요해짐** — PC 화면은 반장·관리자가 쓰고 작업자는 목록에서 선택.
개인 계정은 모바일 단계에서 붙임 (`[[decision-operator-shift]]` 의 개인 계정 결정은 그때 유효).

## Memory

표시 항목·입력 주기·LOT 절단면·전표 흐름의 근거는 `[[decision-shopfloor-execution]]`.
이 카드는 그중 **1차 PC 화면의 구성**만 다룸.

모바일 페이지는 나중에 Desk 밖 독립 주소로(같은 사이트면 DB·DocType 공유라 연동 불필요).
업무 로직이 DocType 훅에 있으므로(`[[decision-business-logic-placement]]`) 입력 경로가 둘이어도
LOT 분기·타수 가산·문서 스냅샷은 한 곳에서 동일하게 동작.
