**별도 화면** (진행 곡선·공정별 상태 — `[[decision-ui-shell]]` B 예외 기준 2).
1차에서는 **수동 발행만** — 생산계획 화면은 2차.

### 목록

| 열 | 원본 |
|---|---|
| 지시번호 | `name` |
| 품목 | `production_item` |
| 수량 (계획/생산/잔량) | `qty` `produced_qty` |
| 진행률 | 계산 |
| 상태 | `status` — 초안·미착수·진행중·완료·중단·종료 |
| 설비 | 주 공정 `workstation` |
| 금형 | `use_mold` 켜짐일 때만 |
| 시작·완료 예정 | `planned_start_date` `planned_end_date` |
| 지연 | 예정일 경과 + 미완료 |

**필터** — 상태 · 품목 · 설비 · 기간 · 지연만

### 상세

```
┌ WO-00042   진행중   ▓▓▓▓▓▓░░░░ 62%              [중단] [완료] ⋯ ┐
│ 품목  FG-A100      BOM  BOM-FG-A100-001    수량 16,000 / 9,920  │
│ 설비  IJ03                                 8/1 08:00 ~ 8/3 12:00 │
├──────────────────────────────────────────────────────────────────┤
│ [자재] [공정] [LOT] [진행]                                        │
└──────────────────────────────────────────────────────────────────┘
```

| 탭 | 내용 |
|---|---|
| 자재 | 소요·투입·잔여, 배치별 투입 이력 |
| 공정 | 작업표(Job Card)별 상태·실적·담당 설비 |
| LOT | 이 지시에서 발번된 배치와 각 수량 |
| 진행 | 계획 대비 실적 누적 곡선 |

**버튼** — `시작` `중단` `완료` `취소` · `실행 화면 열기`

### 생성 폼

| 항목 | 처리 |
|---|---|
| 품목 | 선택 |
| BOM | 기본 BOM 자동, 여러 개면 선택 |
| 수량 | 입력 |
| 시작 예정일 | 입력 (완료일은 Capacity Planning이 계산) |
| 창고 | 회사 기본값 자동, 변경 가능 |
| 공정·설비 | BOM에서 복사, 호기 변경 가능 |
| **다층 전개** | `use_multi_level_bom` **기본 켬**, 건별 해제 가능 |
| 금형 | `use_mold` 켜짐일 때만 (`[[decision-mold-usage-switch]]`) |

### 검증

- 금형 중복 배정 경고 (`use_mold` 켜짐일 때)
- 자재 재고 부족 경고 — 막지는 않음
- 완료 수량이 지시 수량 초과 시 허용 범위 확인

## Why

**다층 전개 기본 켬** — 대부분 연속 생산이라 원자재까지 폭발하는 쪽이 지시 1장으로 끝남.
공용 반제품을 미리 만들어 두는 경우만 그 지시에서 해제하면 재고에서 소비함.
그 재고는 반제품 자체에 대한 별도 작업지시로 만듦.

**자재 목록 직접 편집은 끔** (`allow_editing_of_items_and_quantities_in_work_order`).
켜면 일부 반제품만 재고에서 쓰는 혼합이 가능해지지만, 자재 목록이 BOM과 어긋나도 통과해
소요 계산·원가가 틀어지고 "이 LOT은 BOM대로 만들어졌나"가 불확실해짐. 요구가 실제로 나오면 그때.

## Memory

**생산계획 화면(2차)이 생겨도 이 화면은 대체되지 않음** — 계획은 작업지시를 만들어내는 입구이고,
목록·상세·진행·상태 전환·검증은 그대로. 계획 참조 열 하나가 추가되고 `+ 수동 생성` 이 주 경로에서
보조 경로로 내려갈 뿐. 급건·시험 생산·재작업은 계획을 거치지 않으므로 수동 발행 경로는 계속 필요
(`[[decision-production-planning]]` PP + 수동 병행).

ERPNext Work Order 상태 흐름: `Draft → Not Started → In Process → Completed`,
그 외 `Stopped` `Closed` `Cancelled`.
