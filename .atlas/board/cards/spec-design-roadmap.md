## Memory

전체 설계 로드맵. 결정이 확정될 때마다 해당 항목 체크 + 대응 decision 카드 생성/갱신.

순서 원칙: 마스터 → 추적성 → 실행 → 품질 → 집계. 뒤 단계가 앞 단계의 식별자에 의존하므로
역순 진행은 재작업을 만듦. 단 6번(재고 posting 격리)은 4번 실행 설계가 나와야 지점이 확정됨.

**적용 업종: 범용 MES. 우선 검증 대상은 와이어하네스**, 사출·프레스는 선제 반영
(2026-07-28 정정). 사출·프레스 검토가 낳은 결정(금형 마스터, LOT 단위)은 하네스에도 유효.
