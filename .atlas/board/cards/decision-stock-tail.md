재고 단계 잔여 3건. 큰 결정은 기존 카드에서 완료 — 세부만 확정.

| # | 항목 | 결정 |
|---|---|---|
| 1 | 재생재 혼합률 | **BOM 표기로 기록** — 재생재가 별도 품목이므로 BOM 자재에 신재 0.8kg + 재생재 0.2kg 로 넣으면 비율이 자연히 남음. 별도 기능 없음 |
| 2 | 출하 시 LOT 지정 | **배치추적 품목은 강제** — ERPNext 기본 동작 확인됨 (배치 품목은 배치 없이 출고 불가). 추가 개발 0 |
| 3 | 외주처 창고 | **`외주처` 그룹 창고 추가** — 기존 5개(원자재·WIP·완제품·불량·재생재) + 1. 외주처 여럿이면 하위 창고 |

## Why

1: 혼합률이 그때그때 바뀌는 공장은 BOM과 실제가 어긋나지만, 실제 비율은 투입 배치 수량으로 추적
가능. 변동이 심한 업체는 문진.

2: ERPNext Batch 체계 실측 결과 — `has_batch_no` 품목은 전표에 배치 지정이 강제되고 FIFO 자동
제안까지 기본 제공. 정방향 추적(`[[decision-traceability-screen]]`)의 전제가 기본 기능으로 보장됨.

3: `[[decision-outsourcing-scope]]` 의 무상사급 흐름(supplier_warehouse)이 창고 구조에 실재해야
재고 조회에서 "외주처에 있는 우리 자재"가 보임. `[[decision-warehouse-structure]]` 의
"구조는 최대로 만들고 운용만 끈다" 원칙 그대로.

## Memory

ERPNext 기본 LOT 관리 실측 (재논의 대비): Batch(배치 마스터) + Serial and Batch Bundle(전표의
배치 내역, v15+) + Stock Ledger Entry(이동 기록·잔량 집계). 기본 제공 = 발번 시리즈·제조일·
유효기한·공급처·FIFO 제안·배치별 원가·출고 강제. **비어 있는 것** = 조건 분기 발번, 설비·조·금형 축,
연쇄 추적 조회, 회수 범위 집계 — 전부 우리 설계가 얹는 층. 장부 자체는 그대로 재사용.
